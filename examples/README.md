# Examples Index

This directory contains minimal runtime payload examples for `mova-agent-api`.

Suggested reading order:

1. `agent_request_minimal.json`
2. `policy_admission_minimal.json`
3. `connector_call_minimal.json`
4. `contract_run_start_minimal.json`
5. `contract_run_status_in_progress.json`
6. `contract_run_evidence_completed.json`
7. `human_gate_current_minimal.json`
8. `evidence_response_minimal.json`

Use `npm run validate:examples` or `npm run validate:all` to verify them.
