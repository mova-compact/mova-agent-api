# Operator API Governance

This repository carries both public API docs and operator/runtime material.

Use these boundaries:

- public contract: OpenAPI, validated examples, public runtime parity docs
- operator contract: `operator-guide/`, smoke procedures, repair backlog, approval handling
- internal proof: freeze snapshots, hardening blocks, execution proofs

Do not mix:

- runtime proof docs with language canon
- operator repair backlog with package canon
