# 01. Карта системы

Этот раздел объясняет, кто за что отвечает в MOVA.

## Кто есть кто

### ChatGPT

ChatGPT помогает сформулировать намерение и перевести человеческую задачу в понятный запрос.

Простыми словами: он помогает сказать, что именно нужно сделать.

### Codex

Codex собирает и чинит файлы.

Простыми словами: он помогает менять документацию, код и сопутствующие файлы аккуратно и по делу.

### MOVA API

`MOVA API` допускает и запускает контракты.

Простыми словами: это входной рабочий контур, который проверяет, можно ли запускать процесс, и затем запускает его по правилам.

### Cloudflare

Cloudflare держит рабочий сервер и расписания.

Простыми словами: это место, где система может быть доступна и где могут работать запуски по времени.

### Telegram

Telegram показывает команды, отчёты и подтверждения.

Простыми словами: это удобный экран для оператора, где видно, что случилось, и где можно принять решение, если нужен человек.

### GitHub

GitHub хранит файлы, контракты и историю изменений.

Простыми словами: это хранилище рабочей версии системы и следов изменений.

### Внешние сервисы

Внешние сервисы — это источники данных и действия бизнеса.

Простыми словами: это всё, что находится вне MOVA, но с чем система может работать через разрешённые подключения.

## Как смотреть на систему целиком

MOVA можно представить как связку ролей:

- человек формулирует задачу;
- ChatGPT помогает описать намерение;
- Codex готовит и исправляет файлы;
- GitHub хранит результат работы;
- MOVA API проверяет правила и запускает допустимое;
- Cloudflare держит работающий сервер и расписания;
- Telegram показывает состояние и просит подтверждение, если нужен человек;
- внешние сервисы дают данные или выполняют разрешённые действия.

## Что оператору важно помнить

- MOVA не равна “общему ИИ”.
- Telegram не является источником власти сам по себе.
- GitHub не должен содержать секреты и чувствительные данные без отдельной защиты.
- Внешний сервис всегда должен быть явно разрешён.
- Если система не уверена или ситуация спорная, решение возвращается человеку.
