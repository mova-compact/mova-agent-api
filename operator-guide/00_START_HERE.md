# 00. С чего начать

Этот гайд для человека, который должен безопасно работать с MOVA как с рабочей системой, а не как с “свободным ИИ-агентом”.

После чтения этого блока оператор должен понимать:

- что такое MOVA в рабочем контуре;
- кто за что отвечает в системе;
- как выглядит жизненный цикл запуска;
- что такое ключи и секреты;
- какие базовые правила безопасности действуют для ключей, сред и Telegram.

## Главное понимание

MOVA не делает “что угодно по просьбе”.

Она работает по ограниченной схеме:

человек ставит задачу → контракт ограничивает действия → политика проверяет разрешения → MOVA запускает процесс → Telegram показывает результат → человек подтверждает спорные случаи.

Это значит:

- MOVA не является автономным владельцем решения;
- MOVA не должна выходить за рамки контракта и политики;
- Telegram показывает состояние, отчёты и подтверждения, но сам по себе не даёт власти системе;
- спорные случаи всегда возвращаются к человеку.
