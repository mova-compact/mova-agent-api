# MOVA Agent API Roadmap V0

## Phase 0: repository and product freeze

Establish the repository as the single source of truth for MOVA Agent API V0 and freeze the product boundary.

## Phase 1: schema and action model skeleton

Define the product-local request, action, and response shapes.

## Phase 2: policy admission skeleton

Define deterministic admission structures and decision shapes.

## Phase 3: flat execution skeleton

Define the single-action execution loop without expanding scope.

## Phase 4: connector proxy skeleton

Define the connector-call boundary and narrow adapter shape.

## Phase 5: observation and evidence skeleton

Define observation write paths and evidence response assembly.

## Phase 6: vertical smoke

Define a minimal end-to-end product smoke path across validation, admission, execution, observation, and evidence.

## Phase 7: OpenAPI and validation

Define the public API contract and validation surfaces for the V0 product boundary.
